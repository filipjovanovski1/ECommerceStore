# Test Assets

Use this folder (`src/test/resources`) for any fixtures needed by tests such as:

- Sample images used by controller/service tests (e.g., a small JPG for product images like trousers or hats).
- JSON or CSV fixtures for repository and service tests.
- Template snippets or HTML snapshots used in MVC tests.

If you add images, prefer small files (under ~50KB) and place them in a subfolder
like `src/test/resources/images/` to keep test assets organized.
